# 🚀 Portfolio | Samarth Muktamath

A modern, high-performance portfolio built with **SvelteKit**, **Tailwind CSS**, and **Motion**.

## ✨ Key Projects

- **Portfolio**: A dynamic and interactive website showcasing modern frontend expertise with smooth GSAP transitions and optimized performance.
- **AI Quiz App**: A smart question generation platform featuring real-time scoring and instant feedback built with SvelteKit and TypeScript.
- **Video Summarization**: A powerful Python-based tool that uses YOLO for real-time object detection to summarize key content from long-duration videos.
- **Weather Forecast App**: A seamless weather tracking experience providing 5-day forecasts via the OpenWeather API, built with React and shadcn/ui.
- **SpiceSpirit Cocktails**: A visually stunning landing page focused on motion and storytelling, utilizing GSAP animations and React components.
- **F1 Fan Landing Page**: A dedicated space for racing enthusiasts featuring live standings and driver insights built with React.

## 🛠️ Performance & Design
- **Glassmorphic UI**: High-end dark theme aesthetic with backdrop-blur effects.
- **Fluid Motion**: Premium animations using GSAP and the Motion library.
- **Responsive Navigation**: Custom-built mobile menu with staggered entrance effects.
- **Optimized Experience**: Fast-loading, smooth-scrolling (Lenis), and SEO-optimized.
