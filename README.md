# Portfolio | Samarth Muktamath

A modern, high-performance portfolio built with **SvelteKit**, **Tailwind CSS**, and **Motion**.

![Svelte](https://img.shields.io/badge/Svelte-4A4A55?style=for-the-badge&logo=svelte&logoColor=FF3E00)

- **Glassmorphic UI** for a premium feel.
- **Fluid Animations** via GSAP and Motion.
- **Fully Responsive** with custom mobile navigation.
- **Smooth Content Delivery** optimized for speed.
